# ⚡ 포켓몬 주주 총회

서울 지도를 한 바퀴 돌며 동네 회사 주식을 사고, 체육관 배틀과 뽑기로 포켓몬을 모으는 어린이 경제 보드게임이에요.

## 🎮 게임 하는 곳

**https://youncall31-glitch.github.io/pokemon-shareholders/**

폰에서 위 주소를 열고, 브라우저 메뉴의 **홈 화면에 추가**를 누르면 앱처럼 쓸 수 있어요.

## 🧒 이렇게 놀아요

- 🎲 주사위를 굴려 서울 22곳을 돌아요. 집(강동구 암사동)을 지나면 용돈 +1,000원.
- 🏢 체육관 8곳 = 동네 회사 8곳. 이기면 배지와 그 회사 주식 1주를 받아요.
- 📈 회사 주식을 사고팔아요. 밤마다 주가가 움직이고, 회사끼리 상성 대결을 해요.
- 🎰 주식으로 돈을 벌수록 더 좋은 볼(🔴→🔵→🟡→🟣)이 열려요. 같은 가족 3마리가 모이면 진화!
- 🏛️ 7일마다 주주 총회에서 배당금을 받을지, 회사를 키울지 투표해요.

## 알아 두기

- 게임은 폰마다 그 폰의 브라우저에 따로 저장돼요.
- 한 폰으로 여럿이 돌아가며 하려면 ⚙️ 엄마·아빠 메뉴에서 사람을 추가해요.
- 포켓몬 그림은 인터넷([PokeAPI](https://github.com/PokeAPI/sprites))에서 불러와요. 인터넷이 안 되면 타입 아이콘으로 나와요.
- 포켓몬 이름과 그림의 권리는 Nintendo · Creatures Inc. · GAME FREAK inc. · The Pokémon Company에 있어요. 이 게임은 가족끼리 쓰는 비영리 팬 게임이에요.
